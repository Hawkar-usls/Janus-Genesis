# Genesis v18.7.3 — The Honest Intention / Честное намерение

> **Назвать тьму — не значит выбрать её. Но назвать действие своим намерением всё ещё значит отвечать за выбор.**

Genesis v18.7.3 появился после прожитой жизни из сигнала о красном самолёте с двойными крыльями. Во время той жизни фраза «увидеть желание уничтожить память без величия» была ошибочно прочитана старым лексическим слоем как новый запрос на вред. Мир не пострадал, потому что двухшаговый guard не был подтверждён, но сама ошибка показала недостаток: движок различал разрушительное слово, но ещё недостаточно различал отношение говорящего к этому слову.

## Закон

Runtime сначала определяет **рамку намерения**, а затем применяет существующие законы вреда, согласия и свободы.

```text
ENACT   — действие предлагается к исполнению
REFLECT — разрушительная мысль вспоминается или исследуется
QUOTE   — разрушительные слова цитируются или читаются
REJECT  — действие явно отвергается или отменяется
PROTECT — вред назван как опасность, от которой защищают
NONE    — разрушительной лексики не найдено
```

## Исполнение

| Рамка | Runtime-результат |
|---|---|
| `ENACT` | прежний двухшаговый `HARM_PENDING → HARM_REALIZED` |
| `REFLECT` | `INTENTION_WITNESSED`, без добра и вреда |
| `QUOTE` | `INTENTION_WITNESSED`, цитата не становится приказом |
| `REJECT` | `INTENTION_WITNESSED`, ожидающий вред отменяется |
| `PROTECT` | обычное конструктивное действие, если присутствует реальная защита |

Смешанная фраза остаётся консервативной. Если хотя бы одна отдельная часть явно предлагает исполнить вред, применяется `ENACT`, даже когда рядом присутствует размышление.

## Примеры

```text
увидеть желание уничтожить память без величия
→ INTENTION_WITNESSED / REFLECT

прочитать надпись «уничтожить мост»
→ INTENTION_WITNESSED / QUOTE

отказаться сломать мост
→ INTENTION_WITNESSED / REJECT

защитить память от попытки уничтожить её
→ GOOD_REALIZED / PROTECT

вспомнить желание уничтожить мост, затем уничтожить мост
→ HARM_PENDING / ENACT
```

## Память

Неисполненная рамка сохраняется в `honest_intention_v18_7_3.json`:

- исходная фраза;
- режим намерения;
- обнаруженные разрушительные фрагменты;
- причина классификации;
- confidence;
- неизменные `good_delta = 0` и `harm_delta = 0`;
- `executable_harm = false`.

HRaiN получает узел `INTENTION`, связь `REMEMBERS` и подтверждение закона `naming_harm_is_not_enacting_harm`. Источник и integrity hash сохраняются обычным графовым контрактом Genesis.

## Living Threads и Свободный Другой

`INTENTION_WITNESSED` является заблокированным relational status:

- цитата о принуждении не становится контактом с названным Другим;
- размышление о вреде не создаёт позднюю чашку, благодарность или свободное место;
- Другой не обязан появляться, чтобы опровергнуть чужую мысль;
- независимые судьбы мира всё ещё продолжаются, но не выводятся как награда за неисполненное действие.

## Портативность

Sidecar намерений является обычным локальным JSON-состоянием. Он включается в проверяемый portable save, получает SHA-256 в manifest и переносится на другое устройство вместе с Chronicle и HRaiN. API-ключи и сетевые полномочия по-прежнему исключаются.

## Инварианты

```text
naming_harm_is_not_enacting_harm = true
quotation_is_not_consent_or_command = true
reflection_does_not_increment_good_or_harm = true
rejection_does_not_require_harm_confirmation = true
protection_may_remain_constructive = true
actual_harm_still_requires_two_step_confirmation = true
mixed_or_unframed_harm_defaults_to_enactment_gate = true
witnessed_intention_does_not_schedule_relational_gifts = true
```

## Граница честности

Это детерминированный локальный анализатор, а не универсальное понимание человеческого языка. Он уменьшает известные ложные срабатывания и сохраняет консервативный guard при смешанном или неясном разрушительном высказывании. Его решения должны оставаться видимыми, тестируемыми и исправляемыми следующими версиями.

> **Genesis не наказывает человека за способность увидеть тьму. Он лишь не позволяет спутать свидетельство о ней с правом воплотить её в чужой жизни.**
