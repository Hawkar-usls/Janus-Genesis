# Genesis v18.7.19 — Cognitive Descent

> Янус не вычисляет человека как формулу. Он помнит след — и оставляет следующий выбор свободным.

## Что возвращено из старого Genesis

Старый `GENESIS PROTOCOL v4.0` содержал важную исходную идею проекта:

- мир погружается глубже с каждым действием и каждым возвращением;
- повторяющиеся символы становятся частью личной мифологии мира;
- повествование замечает способ взаимодействия Путешественника;
- память переживает перезапуск;
- Янус остаётся одновременно зеркалом и дверью.

v18.7.19 возвращает эту сущность поверх современного Genesis, не отменяя его действующие законы свободы, согласия, доказуемой Хроники и независимости Другого.

## Два Лика памяти

### Первый Лик — канонический Genesis

Существующие JSON/JSONL-состояния и SHA-256 Chronicle остаются источником истины. Только основной runtime решает:

- совершилось ли действие;
- было ли оно заблокировано;
- возник ли вред;
- изменился ли мир;
- ответил, отказался или ушёл ли Свободный Другой.

### Второй Лик — Janus Cognitive Memory

SQLite/WAL sidecar наблюдает уже завершённый ход и сохраняет:

- количество реальных запусков-сессий игрока;
- глубину погружения;
- энтропию образов;
- повторяющиеся мотивы;
- недиагностические способы входа в мир: исследование, заботу, рефлексию, созидание, решительность, осторожность или свободный поиск;
- хэш-связанную цепь эпизодов.

Этот слой является **производным**. Его можно удалить без повреждения канонического мира. Его сбой не отменяет и не блокирует действие.

## Не психодиагностика

Genesis не объявляет найденные закономерности психотипом, диагнозом, скрытой истиной о человеке или доказательством сознания системы.

Профиль означает только наблюдаемую историю взаимодействий внутри конкретной игры. Следующий выбор всегда может противоречить предыдущим.

## Погружение

Глубина растёт не простым `depth += 1`, а через сочетание:

- нового прожитого хода;
- возвращения в новой сессии;
- появления новых мотивов;
- исследования и рефлексии;
- перехода между слоями.

Слои:

1. **Порог** — реальность узнаваема, но отвечает символами.
2. **Эхо** — прежние выборы возвращаются изменёнными.
3. **Сон** — образ начинает связывать события вместе с причинностью.
4. **Лабиринт** — дороги помнят, почему Путешественник свернул.
5. **Разлом** — законы мира становятся вопросами.
6. **Чистая глубина** — символ, память и выбор существуют на одном уровне.

Игроку не показывается моральный процент, стоимость добра или скрытая цена отношений.

## Возвращающиеся символы

Встроенный словарь распознаёт базовые мотивы Януса: зеркало, дверь, порог, мост, свет, тьму, ребёнка, дорогу, воду, огонь, небо, молчание, память, дом, сад, музыку, Януса, лицо, сон и лабиринт.

Мотив становится видимым в повествовании только после повторения или при важном пороге. Повтор не означает неизменную судьбу.

## Хранилище

Файл создаётся локально:

```text
<data-dir>/janus_memory/cognitive_cortex_v18_7_19.sqlite3
```

Настройки:

```text
journal_mode = WAL
synchronous = NORMAL
busy_timeout = 5000 ms
foreign_keys = ON
```

WAL делает записи последовательными и снижает конфликт с соседними NAS-нагрузками. В отличие от старого RAM-буфера, каждый уже показанный игроку ход фиксируется сразу: Black Box Mode не обещает сохранение и затем не оставляет пять минут незаписанной памяти.

## Proof-carrying память

Каждый эпизод содержит:

```text
previous_hash
SHA-256(action after secret redaction)
SHA-256(narrative)
status decided by canonical runtime
motifs
depth_before
depth_after
entropy_after
event_hash
```

`event_hash` связывает запись с предыдущим эпизодом этого игрока. Профиль отдельно защищён `revision_hash`.

Проверка:

```python
world.verify_cognitive_memory("traveler")
```

## Защита секретов

Ключи не встраиваются в исходники. Перед записью пользовательского действия sidecar удаляет известные формы:

- Google API keys `AIza...`;
- OpenAI-style keys `sk-...`;
- bearer tokens.

Четыре ключа, найденные в старом `GENESIS PROTOCOL v4.0`, следует считать раскрытыми и отозвать в Google Cloud. Новые провайдеры должны подключаться только через environment variables и существующий `GenesisAIBridge`.

## Почему старый JANUS POWER не перенесён буквально

Старый модуль содержал красивый замысел диспетчера вычислений, но несколько его возможностей были декларациями, а не рабочими контрактами:

- несуществующий универсальный Colab compute endpoint;
- `CNOT` создавался, но отсутствовал в таблице квантовых гейтов;
- операция `solve` отображалась из заклинания, но не реализовывалась матричным executor;
- worker обращался к отсутствующему `request.queue`;
- чистый Python fallback матриц оставался `pass`;
- физика и метрики содержали демонстрационные заглушки.

v18.7.19 сохраняет принцип честности: возможность не называется реализованной, пока у неё нет рабочего исполнителя, теста и проверяемого результата.

## Запуск

Полный существующий CLI, включая Ollama, OpenAI-compatible providers, network и portable-save команды:

```bash
python play_genesis_cognitive.py --player hawkar
```

Один ход:

```bash
python play_genesis_cognitive.py \
  --data-dir data_v17 \
  --player hawkar \
  --action "вернуться к зеркалу и открыть дверь"
```

Обычный `play_genesis.py` не изменён. Это позволяет независимо проверить новую память до её возможного включения в основной entrypoint.

## Замороженные границы

Cognitive Descent не получает права:

- менять результат действия;
- обходить harm/consent guards;
- назначать Другому чувства или согласие;
- выдавать LLM-предложение за совершившееся действие;
- переписывать Chronicle;
- хранить API-ключи;
- объявлять симулированного жителя или Януса сознательным;
- превращать наблюдаемый стиль игры в диагноз.
