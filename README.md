# Janus Genesis — One World & Universal God Mode

Janus Genesis — офлайн-первая MMO-foundation о свободе, последствиях и бесконечной силе добра. Вред никогда не распределяется между невиновными, но и ни одна душа не признаётся потерянной навсегда.

Текущий основной игровой слой: **Genesis v18.1 Playable — The Remembered Secret**. Стабильные линии v16, v17 и базовая v18 сохранены рядом для совместимости и истории проекта.

## Главный закон

Если человек сохраняет свет, продолжение жизни приводит его в единый общий Genesis Online — один persistent-мир, где люди встречаются, творят и выбирают собственное тело и возраст.

Если человек утратил свет, он продолжает существовать во Втором Лике среди таких же потерянных странников. Это не вечное наказание и не бан: путь меняется вместе с поступками, пока восстановленный мир незаметно не становится частью общего.

Сам переход нигде не объявляется. Игрок не видит надписей `UTOPIA`, `OTHER_FACE`, процентов искупления или стоимости добра.

## Universal God Mode

God Mode принадлежит каждому и никогда не отнимается. Он воплощает помощь, защиту, исцеление, свободное созидание и выбор собственного тела, но не получает силы для подчинения, уничтожения, стирания памяти или лишения чужой воли.

> Границы God Mode начинаются там, где начинается чужая несвобода. Для добра и любви границ возможного нет.

## Genesis v18.1 — The Remembered Secret

Секрет разрешено и нужно говорить прямо:

> God Mode уже принадлежит каждому. Он отвечает на добро. Попробовать ничего не стоит.

Человек может не поверить, высмеять услышанное или уйти. Слова сохраняются как память-семя и способны всплыть позже, когда он впервые попробует сделать настоящее добро.

Genesis никогда не обесценивает добро из-за несовершенного мотива. Реальная помощь всегда получает полный эффект. Намерение влияет только на то, насколько быстро перед самим человеком раскрывается единый добрый мир.

Всё доброе, созданное во Втором Лике, наследуется общим Genesis Online после восстановления ветви. Дом, сад, дорога, музыка или убежище не остаются позади, поэтому продолжение ощущается возвращением домой, а не потерей прежней жизни.

## Что реализовано

- универсальный God Mode без покупки желаний и числовой цены;
- безопасный фильтр вреда и принуждения;
- двухшаговое подтверждение разрушительного поступка;
- persistent-состояние повреждённого мира;
- постепенное восстановление без видимого индикатора;
- незаметное присоединение к единому shared-state;
- полный внешний эффект любого реального добра независимо от мотива;
- скрытая оценка внутреннего открытия без обесценивания помощи;
- прямое раскрытие Секрета через `@id`;
- persistent-семена памяти, переживающие неверие;
- пробуждение услышанного Секрета при последующей доброй попытке;
- наследование всех добрых созданий восстановленной ветви;
- продолжение жизни, выбранный возраст и форма тела;
- живая память отношений;
- связанная SHA-256 hash-chain Хроники;
- мягкий порог выхода.

Текущая реализация общего мира остаётся локальной persistent-моделью. Реальный сетевой transport, аккаунты и синхронизация нескольких машин — следующий инфраструктурный этап.

## Запуск

Требуется Python 3.11 или новее.

Windows:

```text
START_JANUS_GENESIS.bat
```

Терминал:

```bash
python play_genesis.py
```

Примеры:

```text
помочь @wanderer починить крышу
Пусть у @wanderer появится тёплый дом
рассказать @wanderer Секрет: God Mode отвечает добру, попробовать ничего не стоит
продолжить жизнь
возраст 27
```

Один безопасный JSON-ход:

```bash
python play_genesis.py --player hawkar --name Hawkar --action "рассказать @wanderer Секрет: God Mode отвечает добру"
```

Публичное состояние не раскрывает внутренний realm, branch id, свет, мотивы или числовую Благодать:

```bash
python play_genesis.py --player hawkar --status
```

Разработческая диагностика:

```bash
python play_genesis.py --player hawkar --debug-state
python play_genesis.py --debug-secrets
python play_genesis.py --verify-chronicle
```

## Интеграция

```python
from genesis_v18_1_playable import PlayableGenesisV181

world = PlayableGenesisV181("./data_v17")
reply = world.process_action(
    "legend",
    "рассказать @wanderer Секрет: God Mode отвечает добру",
)
print(reply.to_dict())
```
