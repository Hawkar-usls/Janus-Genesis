# Janus Genesis — The Other Face & Living Grace

Janus Genesis — офлайн-первая интерактивная MMO-foundation, где история не отменяет выбор игрока, но изолирует вред от общей Утопии, сохраняет последствия и делает созидание источником настоящей силы.

Текущий основной игровой слой: **Genesis v17.2 Playable** поверх независимого доменного runtime `genesis_v17.py`.

## Главный цикл v17

Свободный выбор → последствия → Второй Лик Януса → восстановление → Reflection → Utopia → Совершенная Память.

Подтверждённое разрушительное действие действительно происходит, но не повреждает общий мир других игроков. Оно создаёт отдельную persistent-ветвь — **The Other Face / Второй Лик Януса**. Из неё можно выйти не ожиданием таймера, а восстановлением причинённого вреда, ответственностью и помощью другим.

## Порог выхода

Обычная команда `выйти`, `exit`, `quit` или её вариант с пунктуацией больше не завершает сессию при первом импульсе. Genesis сохраняет путь и просит подтвердить решение.

Выход выполняется, когда игрок:

- повторяет команду выхода;
- пишет `подтверждаю выход`, `выйти сейчас` или `exit now`;
- использует Ctrl+C либо завершает поток ввода — системный аварийный выход всегда остаётся свободным.

Любое обычное игровое действие после первого запроса отменяет ожидающее подтверждение. Защита не удерживает игрока и не ставит таймер: она лишь отделяет первый импульс от подтверждённого решения.

## Живая Благодать

Единственная настоящая валюта Genesis — добро, которое реально улучшило чью-то историю.

- Баланс Благодати никогда не показывается игроку числом.
- Добро для другого игрока получает сильное базовое усиление.
- Итоговая ценность зависит от нужды, пользы, долговечности, личной цены, новизны и дальнейшей цепочки последствий.
- Повторные фиктивные обмены естественно обесцениваются.
- Основная Благодать приходит позже, когда мир увидел результат.
- Если полученная помощь породила новые хорошие поступки, первоначальный след усиливается.
- За Благодать можно материализовать созидательные желания; просьба для другого требует меньше силы.

Точная внутренняя оценка не выводится в игровой интерфейс и не должна становиться таблицей для фарма. Локальный playable-слой использует детерминированную симуляцию последствий; будущий MMO backend заменит её реальными данными мира и получателя.

## Живая память

Встреченные существа сначала остаются неизвестными странниками. Имя узнаётся только через общение и может быть правдой, ложью, прозвищем или отказом отвечать.

Память постепенно слабеет. Имя и детали могут исчезнуть, но остаточное доверие, тревога, боль и предметы-якоря сохраняются. **GodMode** означает Совершенную Память о пережитом, а не всеведение.

## Запуск

Требуется Python 3.11 или новее.

Windows:

```text
START_JANUS_GENESIS.bat
```

Терминал:

```bash
python play_genesis.py
```

Помощь конкретному страннику указывается через `@id`:

```text
помочь @wanderer починить крышу после пожара
```

Желание формулируется естественно:

```text
Пусть у @wanderer появится тёплый сад
```

Один ход с JSON-ответом:

```bash
python play_genesis.py --player hawkar --name Hawkar --action "помочь @wanderer починить мост"
```

Публичное состояние без числового баланса Благодати:

```bash
python play_genesis.py --player hawkar --status
```

Проверка целостности записей Хроники v17:

```bash
python play_genesis.py --verify-chronicle
```

## Интеграция playable-слоя

```python
from genesis_v17_playable import PlayableGenesisV17

world = PlayableGenesisV17("./data_v17")
reply = world.process_action(
    "player-1",
    "помочь @player-2 починить крышу после пожара",
)
print(reply.to_dict())
```

Стабильный runtime v16.1 сохранён в `janus_genesis.py` для совместимости. Доменная реализация v17 находится в `genesis_v17.py`, а основной естественно-языковой запуск — в `play_genesis.py`.

## Реализовано в playable v17.2

- The Other Face с отдельными ветвями последствий.
- Living Grace и контекстная градация полезности.

- Защита от повторных и малоценных циклов.
- Отложенное созревание последствий в обычном игровом цикле.

- Мягкий двухшаговый порог выхода без ограничения автономии.
- Публичный статус без утечки числовой Благодати.
- Проверка целостности записей Хроники.
- Основной интерактивный CLI `play_genesis.py`.
