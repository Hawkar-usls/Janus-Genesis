# Janus Genesis — One World & Universal God Mode

Janus Genesis — офлайн-первая MMO-foundation о свободе, последствиях и бесконечной силе добра. Вред никогда не распределяется между невиновными, но и ни одна душа не признаётся потерянной навсегда.

Текущий основной игровой слой: **Genesis v18.0 Playable**. Стабильные линии v16 и v17 сохранены рядом для совместимости и истории проекта.

## Главный закон v18

Если человек сохраняет свет, продолжение жизни приводит его в единый общий Genesis Online — один persistent-мир, где люди встречаются, творят и выбирают собственное тело и возраст.

Если человек утратил свет, он продолжает существовать во Втором Лике среди таких же потерянных странников. Это не вечное наказание и не бан: путь меняется вместе с поступками, пока восстановленный мир незаметно не становится частью общего.

Сам переход нигде не объявляется. Игрок не видит надписей `UTOPIA`, `OTHER_FACE`, процентов искупления или стоимости добра.

## Universal God Mode

God Mode принадлежит каждому и никогда не отнимается.

Он способен воплощать только то, что расширяет жизнь и свободу:

- помощь, защиту и исцеление;
- создание дома, сада, дороги, музыки или знания;
- прощение и восстановление доверия;
- свободный выбор собственного тела и возраста.

Запросы о подчинении, уничтожении, стирании памяти или лишении чужой воли не получают силы. Человек во Втором Лике может впервые обнаружить God Mode именно тогда, когда искренне пожелает добра другому.

> Границы God Mode начинаются там, где начинается чужая несвобода. Для добра и любви границ возможного нет.

## Что реализовано

- универсальный God Mode без покупки желаний и без числовой цены;
- безопасный фильтр вреда и принуждения;
- двухшаговое подтверждение разрушительного поступка;
- persistent-состояние повреждённого мира: тепло, жильё, исцеление, доверие, природа, музыка и связь;
- постепенное восстановление Второго Лика без видимого индикатора;
- незаметное присоединение восстановленного мира к единому shared-state Genesis Online;
- продолжение жизни без обязательной смерти;
- выбор видимого возраста и формы тела;
- живая память отношений через действия с `@id`;
- исправленное обесценивание буквального повторения поступков;
- миграция существующих v17-сохранений;
- связанная SHA-256 hash-chain Хроники v18;
- мягкий порог выхода с аварийным свободным выходом через Ctrl+C/EOF.

Текущая реализация общего мира — локальная persistent-модель. Реальный сетевой transport, аккаунты и синхронизация нескольких машин остаются следующим инфраструктурным этапом; README не выдаёт локальный файл за уже работающий публичный MMO-сервер.

## Запуск

Требуется Python 3.11 или новее.

Windows:

```text
START_JANUS_GENESIS.bat
```

Терминал:

```bash
python play_genesis.py
```

Примеры естественных действий:

```text
помочь @wanderer починить крышу
Пусть у @wanderer появится тёплый дом
продолжить жизнь
возраст 27
```

Один безопасный JSON-ход:

```bash
python play_genesis.py --player hawkar --name Hawkar --action "Пусть у @wanderer появится сад"
```

Публичное состояние не раскрывает внутренний realm, branch id, свет или числовую Благодать:

```bash
python play_genesis.py --player hawkar --status
```

Внутреннее состояние доступно только как явная команда разработчика:

```bash
python play_genesis.py --player hawkar --debug-state
```

Проверка связанной Хроники:

```bash
python play_genesis.py --verify-chronicle
```

## Интеграция

```python
from genesis_v18_playable import PlayableGenesisV18

world = PlayableGenesisV18("./data_v17")
reply = world.process_action(
    "player-1",
    "Пусть у @player-2 появится тёплый дом",
)
print(reply.to_dict())  # realm routing intentionally omitted
```

v18 читает существующие файлы игроков из `data_v17/players` и добавляет новые структуры рядом: `worlds_v18`, `guards_v18`, `shared_utopia_v18.json` и `chronicle_v18.jsonl`.
