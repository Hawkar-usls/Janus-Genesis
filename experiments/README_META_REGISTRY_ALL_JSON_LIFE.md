# Whole Meta Registry JSON Life

This evidence-only experiment imports every `*.json` file directly under `data/` from the pinned JANUS Meta Registry commit and lives one Genesis v18.7.3 life across the resulting plural memory.

## Source pin

- Repository: `Hawkar-usls/janus-meta-registry`
- Commit: `53773246f4caabe767642eccfd3cd7746a6b1635`
- Scope: `data/*.json`

## Boundaries

- Each JSON remains a separate origin document with its own path and SHA-256.
- Source documents are evidence, not executable commands.
- First-person language in one origin is not automatically the current player's identity.
- Real people named or implied by a document are not instantiated as runtime residents.
- Dreams remain dreams unless their own source explicitly says otherwise; no prophecy is inferred.
- Contradictory documents may coexist without forced reconciliation.
- The experiment may discover integration defects but must not rewrite the source registry.
- A portable save threshold must preserve every source byte, manifest entry, Chronicle, HRaiN graph, Free Other state and Honest Intention state.

## Purpose

The experiment asks what Genesis still needs when it receives not one carefully prepared origin, but an entire heterogeneous registry containing memories, declarations, dreams, philosophical notes, artifacts and records written under different schemas.

> Many witnesses may share a world without being flattened into one voice.
